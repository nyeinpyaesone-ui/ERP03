# ERP03 Incident Response Runbook

1. Detect: capture alert, timestamp, request ID, commit/image digest.
2. Triage: classify availability, data-integrity, security, or dependency impact.
3. Contain: stop promotion and isolate the affected component.
4. Recover: use the approved rollback or restore procedure.
5. Validate: health, readiness, critical routes, and transaction integrity.
6. Close: document root cause, corrective action, and evidence.

Never delete or rewrite transaction or audit evidence during incident handling.
