This directory contains Architecture Decision Records (ADRs) for ERP03.

|-----|-------|--------|
| [0001](0001-modular-monolith.md) | Modular Monolith Architecture | Accepted |

## Format

Each ADR follows the [MADR](https://adr.github.io/madr/) format:
- Status (Proposed/Accepted/Deprecated/Superseded)
- Context
- Decision
- Consequences
- Alternatives Considered
