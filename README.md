# ERP03

Production-focused AI ERP modular monolith.

## Architecture
- FastAPI backend
- React/Vite frontend
- PostgreSQL and Redis as required runtime dependencies
- Local Ollama AI integration
- Authentication, business profile, capabilities, policy, context, runtime, workflow, approvals, audit and control-tower modules

## Engineering principle
Correctness first. Keep boundaries explicit, optimize measured bottlenecks, and avoid speculative infrastructure.
